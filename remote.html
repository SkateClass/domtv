Подключение

По умолчанию — локальный тест. Для телефона разверните новый Apps Script из пакета. Настройки старой версии не используются.

Один активный плеер. При переходе между режимами сохраните адрес и обновите обе страницы.

Воспроизведение и восстановление

Алгоритм: одна повторная попытка → другие активные источники канала → резервные каналы включённых сценариев. Общий предел: 20 попыток или 5 минут. Архив не участвует.

Буфер сглаживает краткие провалы. Если сеть постоянно медленнее потока, снизьте качество. Для внешних iframe статус и качество не управляются этим приложением.

Перенос данных

Экспорт не содержит PIN, сессий и адреса сервера. Импорт каналов добавляет источники, но не удаляет старые. Большой каталог импортируйте на ПК, не через облачную команду пульта.
