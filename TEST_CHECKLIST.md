# Проверка перед ежедневным использованием

## Без Google
- [ ] Плеер и пульт открываются без ошибок на Pages.
- [ ] «Тестовый эфир» показывает движущиеся часы.
- [ ] Пульт отображает playing и актуальное время.
- [ ] Stop с пульта останавливает ПК; retry возобновляет.
- [ ] Вторая вкладка плеера не становится активным приёмником.
- [ ] При закрытии плеера пульт в течение 25 секунд показывает отсутствие связи.
- [ ] Канал/источник можно архивировать и восстановить; обновление не снимает архив.
- [ ] Импорт-экспорт полного JSON возвращает настройки и сценарии.
- [ ] Сценарий с временем на ближайшую минуту и тестовым каналом исполняется при открытом ПК.
- [ ] Выключенный сценарий не исполняется.
- [ ] Новый каталог добавляет источники, не удаляя прежние.

## С Google
- [ ] setup создал отдельную таблицу, старые данные не затронуты.
- [ ] Один новый /exec в плеере и пульте; разные ролевые сессии после входа по PIN.
- [ ] Телефон переключает тестовый канал и получает подтверждение.
- [ ] Второй плеер не перезаписывает состояние первого.
- [ ] После отключения первого аренда освобождается не позже следующего цикла после 30 секунд.
- [ ] Ошибки сервера отображаются прямо в диалоге настроек.
- [ ] Изменение сценария на телефоне появляется на ПК после подтверждения.
- [ ] Несуществующий/архивный sourceId вызывает явную ошибку, а не подстановку другого URL.
- [ ] Повтор команды с тем же ID не воспроизводит обычное действие повторно.

## Реальное ТВ
- [ ] Россия 1 и Россия 24: проверить HLS отдельно от iframe; записать конкретные рабочие sourceId.
- [ ] Источник с низким bitrate запускается первым; ручной выбор качества работает при наличии вариантов.
- [ ] При кратком buffering источник не меняется мгновенно.
- [ ] При устойчивом сбое запускается ограниченное восстановление.
- [ ] При stop/pause/blocked нет бесконечного самозапуска.
- [ ] Работает резерв по включённому сценарию подходящего дня.
- [ ] На старом ПК нет неприемлемого роста памяти в течение 1–2 часов.
- [ ] Измерены фактические задержки и квоты Google перед длительной эксплуатацией.
